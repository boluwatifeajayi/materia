## T05 Recompute engine

```
TASK T05: Recompute engine.

Read docs/ARCHITECTURE.md section 6 first.

This is the load bearing component of the entire project. Every impact
figure in the submission and the ground truth materiality of every seeded
mutation both come from it. Treat correctness here as more important than
anything else you will build.

Build src/materia/recompute.py:
  - evaluate a workbook's AST in topological order
  - apply a single cell patch and recompute
  - return the delta on each declared output cell

Testing standard for this task, higher than elsewhere:
  - hand computed expected values for every supported function
  - a multi step dependency chain where a patch three levels deep
    propagates correctly to the output
  - cross sheet propagation
  - IF branches on both sides
  - a patch that changes nothing must return a zero delta, not an error

Show me the full test output. If any test fails, do not commit. Tell me.

Then commit, push, update TASKS.md, and stop.
```

## T21 Materiality gate

```
TASK T21: Materiality gate. This is the change the whole project claims.

Read docs/ARCHITECTURE.md section 7.

output exceeds the threshold, default 1%, from config.yaml.

Everything below threshold is counted and summarised, never silently
dropped. The gate is the ONLY thing that assigns IMMATERIAL, and it does so
by reclassifying an ERROR whose verified delta falls below the threshold.
Assert in code that the four buckets (finding, intentional, inconclusive,
immaterial) are mutually exclusive and sum to the detector candidate
count.

Then rerun on OpenAI, full corpus, and record as changelog Iteration 3.

Check C11 specifically: its mutation must appear in the SUPPRESSED count,
not in the findings and not missing entirely. Those three outcomes are very
different and the distinction is the product.

Estimate cost, wait for approval, run. Show me the headline table and the
C11 result. Then commit, push, update TASKS.md, and stop.
```

```
    a chat bubble or a toast.
```
